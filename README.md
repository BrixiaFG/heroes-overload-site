# Heroes Overload website

The game's website on GitHub Pages: home, Support, Privacy Policy and Terms of Service, in English and Italian (`it/`).

- Edit the texts in `build.py`, run `python3 build.py`, commit the pages it writes.
- Plain HTML with the game's fonts (served from here) and colours: no scripts, cookies, analytics or outside requests.
- The game links here from Settings and the title screen (`LINKS` in the game's `game/screens/squad.js`).
